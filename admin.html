🚚 Services de Livraison
Configurez vos tokens API pour synchroniser automatiquement les statuts de livraison
⚡
Recommandé : utiliser n8n comme proxy API. Les navigateurs bloquent les appels directs aux APIs de livraison (CORS). La meilleure approche : votre site envoie la demande à n8n → n8n appelle l'API du transporteur → n8n met à jour le statut via webhook retour. Vous pouvez aussi activer le Mode Direct (tente l'appel direct, utile si le transporteur autorise CORS).

💡 Architecture Recommandée : Airtable + n8n (open-source, gratuit)
📊 Airtable (Base CRM)
Base de données pour leads, commandes, clients. API gratuite. Vues Kanban, Calendrier, Galerie. airtable.com →
⚡ n8n (Automatisations)
Open-source, auto-hébergeable sur un VPS à ~6$/mois. Connecte site → Airtable → Meta/TikTok → WhatsApp. Zéro coût par opération. n8n.io →
🔗 Connexion Site → CRM
Chaque commande envoie un webhook à n8n → enregistrement Airtable + envoi pixel conversion sur toutes les plateformes + notification WhatsApp.
